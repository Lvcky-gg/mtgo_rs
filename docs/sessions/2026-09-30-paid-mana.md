# Resumed from Claude: paid mana abilities

Read the Brain architecture, ADR context, and both September 30 session handoffs.
The latest baseline reported 8,355 / 34,898 fully playable cards (23.9%); coverage
has not been remeasured in this session.

Implemented manual activation of mana abilities with mana and fixed life costs.
The compiler accepts the supported cost shapes, and the engine pays input before
resolving output immediately. Payment reserves the source so another ability on
that permanent cannot fund its activation. Life reservation also constrains
Phyrexian input payments. Fixed mixed-colour outputs are accepted.

Automatic payment planning still excludes sources with input mana or life costs.
Players must activate those sources and float their output before casting. A full
planner for chained paid sources and a bot policy that uses them remain unfinished.
Supported output syntax does not include choosing between bundles of mana.

Regression coverage: input payment followed by casting, self-funding rejection,
life payment and insufficient life, and mixed-colour output. Updated compiler
rejection tests to reflect the expanded supported grammar.

Validation: cargo test --workspace --all-features (639 passed); cargo clippy
--workspace --all-targets --all-features -- -D warnings (clean). Socket tests need
execution outside the filesystem/network sandbox.

Next work from Claude's handoff: multi-face casting; planeswalker loyalty and
attacking planeswalkers; prevention; copy effects; granted non-keyword abilities.
The previously documented shuffle-seed information leak also remains open.

This handoff is stored in the repository because the Brain vault is outside the
writable workspace. No initial git commit was created; repository files remain
untracked as they were at session start.
