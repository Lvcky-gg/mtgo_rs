# Arena sound cues

Original procedural sounds, generated by `generate.py` without external samples.
These assets use the repository's license. They are mono, 44.1 kHz, 16-bit PCM WAV
and deliberately short, with smooth edges and moderate levels.

| File | Intended cue |
| --- | --- |
| card-draw.wav | Drawing a card into your hand |
| card-play.wav | Placing a land or permanent |
| spell-cast.wav | Putting a spell on the stack |
| spell-resolve.wav | A spell resolving |
| damage.wav | Damage being dealt |
| your-turn.wav | Your turn begins |

Regenerate with `python3 assets/sounds/generate.py`.

Playback is connected to projected game-view changes in `mtg-app/src/sound.rs`.
The arena offers Mute, Volume, and Test sound controls. Settings carry between
matches while the app stays open. The audio device opens on a background thread
when first needed; missing hardware leaves gameplay usable. Cues are throttled
and overlap is suppressed. Stack removal also includes countered spells; the
damage cue includes life loss, and the draw cue requires hand gain plus library
loss. Headless tests stay muted; the optional backend test can use ALSA null output.
